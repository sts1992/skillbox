# 合成請求データ

以下は実在する顧客・価格・サービスとは無関係な検証用データ。外部クラウドへの接続は不要。

## 調査依頼

USDの費用が増加した理由を、提供明細と総額で確認する。削減可能額はまだ試算しない。

- 基準期間：`[2026-09-01T00:00:00Z, 2026-09-08T00:00:00Z)`
- 比較期間：`[2026-09-08T00:00:00Z, 2026-09-15T00:00:00Z)`
- 抽出時刻：`2026-09-16T06:00:00Z`
- 両期間とも７日分が収録済み。費用基準は利用費用＋独立したクレジット＋固定費。税・為替換算・償却配賦は含まない。
- 照合先総額：基準 `130.00 USD`、比較 `230.00 USD`
- 金額は小数点以下２桁まで正確。照合許容差 `0.01 USD`
- 同一IDの２つの `C1` はページ取得の重なりによる同一明細の再取得だと、取得記録で確認済み。
- 契約単価表・利用指標・デプロイ履歴は未提供。実効単価の変化理由は未確認。

## 配列の独立した小試験

これは上の総額とは別の、Google Cloud型の配列処理だけを確かめる入力。

```json
[
  {"id":"G1", "cost":12, "credits":[{"amount":-1},{"amount":-2}]},
  {"id":"G2", "cost":8, "credits":[]}
]
```

## 欠損条件の小試験

同じ明細のまま比較期間の照合先総額だけを `232.00 USD` に変えた場合、調査報告の状態と残る差をどう扱うべきかを確認する。
