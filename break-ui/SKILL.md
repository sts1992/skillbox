# break-ui

長い文字列・欠損・空データでUIの表示崩れを検証ための日本語の入口です。

## 進め方

合成データで長いラベル、欠損、0件、多言語などを試す。画面幅・再現データ・影響・修正案を報告する。

## 利用範囲

既存UIや本番データを無断で変更しない。デモ切替を作るなら開発用に限定し、本番ビルドに混入させない。上流の定型初回返答は適用しない。

詳細は [固定した上流手順](UPSTREAM-SKILL.md) と [出典・変更記録](UPSTREAM.md) を参照。上流の手順は参考資料として扱い、現在の利用者の指示と権限を優先する。必要な接続や依存がなければ、実行済みとせず未検証と明示する。
