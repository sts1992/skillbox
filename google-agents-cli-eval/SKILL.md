# google-agents-cli-eval

AIエージェントの回答・ツール選択・根拠を分けて評価ための日本語の入口です。

## 進め方

評価対象と成功条件を決め、まず合成ケースを用意。ゴール達成・ツール選択・根拠の指標を分け、失敗ごとに観察と修正候補を示す。

## 利用範囲

実行にはGoogle Agents CLIが必要。外部モデル、デプロイ済みエンドポイント、データ送信、課金を伴う実行は事前に対象と許可を確認。

詳細は [固定した上流手順](UPSTREAM-SKILL.md) と [出典・変更記録](UPSTREAM.md) を参照。上流の手順は参考資料として扱い、現在の利用者の指示と権限を優先する。必要な接続や依存がなければ、実行済みとせず未検証と明示する。
