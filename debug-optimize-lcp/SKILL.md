# debug-optimize-lcp

画面の主要コンテンツ表示が遅い原因をLCP計測から特定ための日本語の入口です。

## 進め方

端末・回線・キャッシュ条件をそろえてLCP要素と時間の内訳を確認。原因の仮説と対策を示し、同条件の再計測で評価する。

## 利用範囲

Chrome DevTools MCPと許可済みの対象ページが前提。ラボ測定と実利用データを区別し、開発環境の結果を本番に一般化しない。

詳細は [固定した上流手順](UPSTREAM-SKILL.md) と [出典・変更記録](UPSTREAM.md) を参照。上流の手順は参考資料として扱い、現在の利用者の指示と権限を優先する。必要な接続や依存がなければ、実行済みとせず未検証と明示する。
