# promql

PromQLのエラー率・レイテンシ・SLO・カーディナリティを点検ための日本語の入口です。

## 進め方

クエリ、データソース、期間、スクレイプ間隔、期待する系列を確認。ラベル消失、欠損、分母ゼロを区別し、変更案と根拠を提示する。

## 利用範囲

まず既存クエリまたは合成データで確認。本番照会は許可済みの読み取り権限と、負荷を抑えた時間範囲を使う。

上流の認証コマンドをそのまま転記せず、許可済みの読み取り専用接続を使う。トークンをコマンド引数やログへ出さない。クエリの範囲を絞り、顧客識別子や機密ラベルを外へ送らない。

詳細は [固定した上流手順](UPSTREAM-SKILL.md) と [出典・変更記録](UPSTREAM.md) を参照。上流の手順は参考資料として扱い、現在の利用者の指示と権限を優先する。必要な接続や依存がなければ、実行済みとせず未検証と明示する。
