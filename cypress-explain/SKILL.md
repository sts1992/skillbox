# cypress-explain

既存のCypressテストが保証することと抜けを説明ための日本語の入口です。

## 進め方

spec、設定、fixture、カスタムコマンドを読み、操作と検証の意図を根拠付きで説明。実行結果と静的な推測を分ける。

## 利用範囲

読み取り専用。テストの実行・修正は含めない。上流固有のツール指定は、この環境で許可された同等手段に読み替える。

詳細は [固定した上流手順](UPSTREAM-SKILL.md) と [出典・変更記録](UPSTREAM.md) を参照。上流の手順は参考資料として扱い、現在の利用者の指示と権限を優先する。必要な接続や依存がなければ、実行済みとせず未検証と明示する。
