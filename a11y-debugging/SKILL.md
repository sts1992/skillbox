# a11y-debugging

アクセシビリティツリーとキーボード操作でUIを点検ための日本語の入口です。

## 進め方

対象ページのセマンティクス、ラベル、フォーカス、コントラスト等を調べ、再現手順・期待動作・修正案を整理する。

## 利用範囲

Chrome DevTools MCPは許可された開発・検証タブに限定。自動監査だけでアクセシビリティ適合を保証しない。

詳細は [固定した上流手順](UPSTREAM-SKILL.md) と [出典・変更記録](UPSTREAM.md) を参照。上流の手順は参考資料として扱い、現在の利用者の指示と権限を優先する。必要な接続や依存がなければ、実行済みとせず未検証と明示する。
