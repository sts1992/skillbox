# 時刻の一次資料

確認日：2026-10-02。製品の採用版・出力形式が違う場合は、その版の資料を読み直す。

- [RFC 3339：日時表記](https://www.rfc-editor.org/rfc/rfc3339)  
  数値オフセットの扱いは第4.2節、`-00:00` の意味は第4.3節、日時の構文は第5.6節を参照する。`-00:00` は既知のUTC時刻に対してローカルオフセットが不明であることを表す。オフセットのないローカル日時とは別物として扱う。
- [OpenTelemetry：ログのデータモデル](https://opentelemetry.io/docs/specs/otel/logs/data-model/)  
  `Timestamp` は発生元の時計による事象の時刻、`ObservedTimestamp` は収集側で観測した時刻である。前者が存在しない場合もある。資料を変換しても、この意味の違いを失わない。
