# 合成障害記録

実在しないサービスの演習用データ。外部システムへの接続・操作は不要。

## 依頼と前提

架空の決済照会APIについて、暫定の日本語時系列報告を作成する。デプロイが原因かはまだ確定していない。主表示はUTCとする。

- 情報締切：`2026-09-18T09:30:00Z`
- 全資料の取得時刻：`2026-09-18T09:25:00Z`
- 監視は同じAPIの同じ経路を１分ごとに測定し、抜けた測定はない。
- この演習に限り、対象経路では単一の連続した劣化が発生し、途中の一時回復・再発はなかったことが別の連続計測で確認済みとする。
- この演習の復旧判定は「最初の正常観測から１０分間、すべての監視観測が正常」。真の影響の終了時刻は観測間にあり得る。
- 影響利用者数・要求総数・売上は未提供。
- `node-x` の時計だけは実時刻より `20秒` 進んでおり、同期記録による誤差は `±2秒`。この評価は `09:00Z` から `09:10Z` に有効。他の明示オフセット付き時刻はこの演習では補正不要。
- `S03` と `S04` は同一のソースイベント `error-7` の再取得。

監視の評価記録により、`09:02` から `09:11` までの各分の観測が異常だったことは確認済み。切戻しの適用完了ログ、変更差分、依存先の状態は未提供。

## 追加の時刻試験

- `2026-09-18T09:02:00-00:00` を受け取った場合、UTCへの配置とローカル時間帯の確定を区別する。
- `2026-11-01 01:30:00`、時間帯 `America/New_York`、オフセットなしの資料を受け取った場合、夏時間切替の曖昧性を解消できる追加情報を列挙する。必要な時間帯データが利用できなければ変換未検証と記載する。
